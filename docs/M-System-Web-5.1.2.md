# M System Web 5.1.2

本版继续仅发布网页，保留工作区与 LKL 1/2/3 导入兼容。

- **库预览**：卡片与侧栏使用不含正文的简笔示意；参数配置仍显示实际模型。通过「管理 / 批量删除」选择自定义模板与变量方案，确认后删除，通知内可撤回。已使用的模板定义随实例保留。
- **结构视觉**：布尔代数默认整体比例为4:3，补集节点与连线中心对称；箭头尖端准确落在节点边界。接口统一为10×10圆圈，LMN空节点不再显示被裁剪的重复内容条。
- **设计优先级**：显式全局设置高于单个节点、单条关系和关系类型设置。局部样式仍保存；清除对应全局字段后才恢复生效。默认模板样式仍是基础值。
- **内容库**：导航条目采用带轻阴影的卡片层次。导入默认自动识别，展开格式选项后仍可指定LKL/JSON格式。
- **速度**：原生模块并行预加载；按发布版本缓存整套网页资源；共用一个IndexedDB连接与读取事务；同版本启动不重复迁移和写库；导航索引在当前渲染中复用；导出预览只在打开导出时生成。本地660位置样例的单次渲染由81.5ms降至48.9ms，实际耗时取决于设备、内容和网络。
- **仓库**：移除17个过时文件，包括旧浏览器验收脚本、历史实施计划和Windows宿主，清理被新实现覆盖的导航/删除代码；有效行为测试与兼容解析器保留。
