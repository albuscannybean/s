# M System Web 5.1

The knowledge library now uses one canonical location index for its tree, search and breadcrumbs. Construct placements have one home, reference appearances point back to that home, and deep rows wrap within a bounded sidebar indent. Expanding and collapsing a branch no longer resets on every repaint.

- Directed sequence, dependency and proof views share the parameterized directed graph family. Venn diagrams share a two/three-set family. Historical templates remain resolvable, and earlier directed instances keep their saved definitions.
- Center-and-facets structures support peripheral count, optional numbering, formats and stable growth. New graph objects continue the current naming sequence.
- Relations retain independent IDs and routes, including parallel/reverse edges and self loops. Long labels wrap with opaque backgrounds and default centered placement; automatic routes avoid intervening cards. Boolean Hasse layouts use wider, compact ranks.
- Chinese and English interfaces share a translation catalog, including builtin metadata, document editing, mathematics tools and the LKL guide. User titles and document bodies remain unchanged.
- Web builds generate their offline asset list and current authoring contract from the shipped modules.

Validation: 223 Node tests; both Edge browser suites, including deep search addresses, collapse/reopen, no horizontal overflow, optional center numbering, English metadata, portable image paste/upload, matrix calculation, plots, LKL round-trip and offline reload. Mathematical models with different invariants or computation remain distinct.

The L System rules are maintained in two downloadable Factory core documents: semantics and syntax. They require a current online catalog and a proof that parameters, instance edits, layout and composition of existing structures cannot meet the need before permitting a new template.
