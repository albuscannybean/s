# M System Web V5.1.1

本次发布只更新网页。LKL 2.1、LKL 3 档案和现有工作区保持兼容。

## 结构库修复

- 原来的自动避让把文字与节点碰撞转成折线路由，覆盖了直线和圆弧选择。现在路由负责线形，文字层负责标签避让；单独和并行关系保持独立身份。
- 修正配置窗口的错误自调用。库卡片、配置预览与实际画布使用同一份参数化模型与几何引擎。非法参数显示错误并阻止插入。
- 偏序的新建默认是四元素菱形；仍可明确选择空白，并从空白画布进入参数设置或添加元素。已有空白结构保留原意。偏序环检测不会再无限排队。
- 布尔代数保持较扁平的 Hasse 布局和真实覆盖边；模结构保留圆弧，并为节点和标签预留空间。
- 源码先恢复整体状态，再应用实际变更。旧拓扑快照不会覆盖关系编辑。单边外观优先于全局默认；源码校验遵守结构的拓扑能力，允许合法扩展的偏序往返，保护生成结构的数学端点。

## 内容库操作

知识、独立正文、结构、画板及其他已有内容都能在真实地址中访问。正文、图片笔记和结构可独立存在；新建独立结构不会再自动制造空白知识。

- 左栏「＋ 正文」「＋ 结构」在内容库根目录新建独立内容。
- 对条目右键或点击「···」可打开、重命名、更改内容地址、剪切、复制、粘贴或删除；按对象能力显示可用操作。
- 「更改内容地址」可搜索知识或容器位置。拖到目标知识/容器可移动，按 Ctrl 拖动可复制，拖到根目录可取消归属。
- 左栏聚焦时支持 Ctrl/Cmd+A、X、C、V，Delete、F2 和 Alt+M。正文输入框保留正常文字快捷键。
- 「多选」与批量管理支持按类型及未归类内容筛选。删除前展示影响范围，并支持撤销。不会自动删除旧的空白内容。

移动遵循唯一主要归属，引用视角保持引用；禁止把内容移入自身后代或不兼容/已占用的单值容器。复制为新身份并重连副本内部引用。删除、移动和复制先在副本状态中验证，再整体提交。LKL 导出按移动后的归属包含后代。

## 验证与发布

自动回归涵盖全部 35 个内置模板的有限几何与源码往返、全部 28 个公开库入口的配置与预览、关系样式、偏序有效性、跨归属内容操作、LKL 往返、中文/英文界面、图片、数学绘图和离线启动。Web CI 增加专用的结构与内容库浏览器回归。
