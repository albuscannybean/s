# 发现室：第一组函数列材料

## 设计原则

发现室不把数学学习规定为线性步骤。用户可以先看任意样本，改变参数、定义域和观察点；可以比较两个对象，也可以只记录一个暂时无法解释的现象。提示、知识档案、题目和 AI 都是可调用的资源，而不是强制流程。

## 当前样本

| ID | 对象 | 主要可观察现象 |
| --- | --- | --- |
| SEQ-POWER | (x^n) | 固定点与右端点附近移动点的差别；定义域改变会改变一致性 |
| SEQ-LINEAR | (x/n) | 误差上界随 n 衰减；有界定义域与无界定义域的差别 |
| SEQ-SINE | (sin(nx)/n) | 频率增加而振幅减小；全域统一上界 |
| SEQ-SPIKE | (max(1-2n|x-1/n|,0)) | 峰值位置移动、宽度缩小而高度不变 |
| SEQ-PEAK | (nx e^{-nx}) | 峰值位置趋近 0，但峰值高度保持 (1/e) |
| SEQ-RATIONAL | (x/(1+nx)) | 单调性与统一估计如何控制全域误差 |
| SEQ-RECIPROCAL | (1/(1+nx)) | 端点特殊值、极限函数不连续与定义域截断 |

每个样本都提供安全的数值求值函数、移动点选择、全域误差（或上界）估计、一致性判别、相关知识 ID 与相关习题 ID。数据校验必须确保所有引用均指向现有档案。

## 交互

- (n) 滑块控制当前函数项。
- 定义域可以在 ([0,1])、([0,0.8])、([0.2,1]) 之间切换。
- 固定观察点 (x_0) 可以连续移动。
- 图像同时展示 (n=1,2,4,8) 与当前 n 的曲线。
- 数值表并列展示 (f_n(x_0)) 与 (f_n(x_n))，使固定点和移动点的差异可见。
- 可选择第二个样本进行并排比较。
- 观察、猜想、反例/疑问分开保存到既有个人批注档案。
- AI 导出包含样本、参数、数值、对照对象和个人笔记，不包含预设结论或答案。

## 解释边界

样本给出的“一致/不一致”是针对所选固定定义域与该样本已知逐点极限的数学结论。正弦样本展示的是 (sup |f_n|le 1/n) 的统一上界，不把它误标为所有区间上的精确上确界。幂函数列在 ([0,1]) 上的逐点极限在 x=1 处为 1；在 ([0,0.8]) 上才处处趋于 0。端点样本 (1/(1+nx)) 在 x=0 处极限为 1，在 x>0 处极限为 0。
