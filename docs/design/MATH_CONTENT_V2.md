# 数学 · LMN：第一批可学习的公开数学内容

## 为什么这个版本不同于 V1

V2 首次提供可直接阅读的课程、知识、题目与方法。V3 在此基础上将默认学习入口改为发现式探索：先呈现丰富的具体样本，允许用户改变参数、比较对象、追踪固定点与移动点，再由学习者决定何时查看提示、抽象、证明或练习。原有解题工作台保留为可选工具，不再被当作所有数学学习必须经过的固定流程。

上一版将学习会话、课程容器与旧结构工具整合到了一致的阅读 UI 中，但首页仍然缺少可直接打开的公开数学资料。V2 的第一优先级是**第一次访问、浏览器没有私有数据时，也能学习真实数学**。

## 发布内容和质量边界

- 一个完整课程单元：`数学分析（二）→ 函数列：逐点收敛与一致收敛`。
- `ANA-UC-K01`—`K10`：10 篇含定义、证明、直觉、例子、反例与边界的知识档案。
- `ANA-UC-P01`—`P20`：20 道原创习题，含题目、前置知识、可复用方法、分层提示、经过逐条逻辑核查的示范解答、迁移问题。
- `ANA-UC-M01`—`M05`：5 张方法档案，包含「触发条件—核心动作—有效原因—适用边界」。
- 来源标记为原创；尚未复制第三方教材。以后若引入外部材料，必须建立逐条的权利与署名数据。
- 项目内置 `validateMathContent` 和公式渲染测试，检查 ID、依赖成环、交叉引用、必填正文和 KaTeX 公式。

## 公共资料与私人数据：两条轨道

1. 公开教材版本化保存在 `packages/learning/math-content.js`，随 GitHub 发布。稳定 ID 绑定课程、知识、题目和方法。它本身不写入 `Knowledge` 或 LKL3 数据库。
2. 现有用户的 `Knowledge`、图形结构、LKL3 和个人课程原样保留。
3. 新的私人批注写入 IndexedDB `mathAnnotations`（数据库 v9 自动增加 object store，非破坏性升级）。可导出/导入 `lmn-math-annotations/1`，导入按照更新时间保留较新的本机记录。
4. 题库解题会话沿用 `studySessions`，仅新增可选 `problemId` 字段。旧学习记录仍然可导入，旧 uniform-N 示例仍可继续。
5. AI 导出的 `lmn-study-context/1` 在有题目来源时新增 `problemId`、`problemStatement`、`knowledgeIds`、`methodIds`，但**不携带参考解答**。
6. 学习阶段的参考答案要先保存至少一次独立尝试才解锁；公开题目档案中的答案需主动展开。AI 反馈仍须经格式校验和用户确认才保存。

## 导航与使用

顶部导航：`首页 / 发现 / 课程 / 题库 / 知识 / 方法 / 记录 / 应用数学`；首页优先呈现具体样本，发现室提供图像、参数、固定点/移动点数值、对照样本与个人观察记录。文档标签只显示实际打开的文档，不再重复承担模块导航；旧内容库与结构库由工具箱调用。

问题与知识是多对多关系：同一习题可关联多个 Knowledge 和 Method。课程按章节提供有序导航；知识的前置关系构成独立的有向无环图。列表支持筛选、搜索和响应式阅读布局，正式公开内容可通过 `#math/...` 深链访问。

## V3：发现式探索材料

新增 `packages/learning/math-discovery.js` 与发现室视图，提供 7 个函数列样本：幂函数列、线性缩放、振荡衰减、移动尖峰、移动峰、有理函数列和端点现象。每个样本关联既有知识档案与题目。用户可以调节 n、定义域和固定观察点，比较多个 n 的曲线、固定点与移动点的函数值，也可以选择第二个样本对照。数学结论默认折叠，避免在观察之前提前给出结论。

观察、猜想和反例分别写入现有 `mathAnnotations`，不新增 IndexedDB 版本；原批注 JSON 备份仍然适用。发现上下文可复制给 AI，其中包含样本、参数、数值、对照对象和个人笔记。

## 已知限制与后续建设

- 目前只发布一个完整单元，不用其他空课程冒充教材覆盖面。
- 对掌握程度的五级标签是用户手动标记，系统只显示关联会话/尝试作为证据，不进行未经验证的自动评分。
- 个人批注和学习记录仍存于此设备浏览器；不同数据类型要分别导出备份。没有账号同步或在线 AI 密钥。
- 公共内容由 GitHub PR 维护，网站中尚未开放站长直接编辑或多人提交。
- 底部工具箱已提供入口；画布中的可拖放模板将作为独立后续功能完善，不以此阻塞首次完整学习闭环。

## 验收路线

1. 全新浏览器打开 `/apps/web/`，第一屏首先可见具体观察样本，并能直接进入发现室。
2. 在发现室切换 7 个样本，调节 n、定义域和固定观察点，比较曲线与数值。
3. 记录观察、猜想和反例，刷新后确认恢复，并导出探索上下文。
4. 从样本关联进入知识档案和习题，再按需要调用解题工作台。
5. 进入“题库”→ `ANA-UC-P02`，查看题目、所需知识及方法。
6. 点击“开始独立解题”，提交一次尝试，逐步解锁提示和参考解答，导出 AI 请求。
7. 返回知识库浏览 `ANA-UC-K02`，编辑私人批注，刷新后查看保留内容。
8. 导出、导入批注；确认不会影响旧 Knowledge、LKL3 和学习会话。
9. 用手机宽度检查发现室图像、样本卡片与数值表不溢出；确认旧结构库仍可打开。

发布审核回归：`node tests/qa-math-content.mjs` 检查公开课程与35个条目、题库筛选、习题会话、私人批注的刷新与导入导出、待保存批注与导入之间的先后顺序，以及 v8→v9 后16个旧 store 的数据原样保留。旧内容库在公开档案中沿用首页覆盖导航状态；批注先校验日期和记录，再完成待保存内容后合并，避免旧的延迟写入覆盖较新导入。
