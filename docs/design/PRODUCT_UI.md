# 产品界面与工作区关系

## 用户路径

1. 首页可从一个数学问题建立可编辑的学习正文，按概念理解、证明、解题和知识整理提供轻量写作提纲；所有提纲都只是正文内容，不新增知识 schema 或强制图谱。可选择归档到已有章节，也可以暂不归档。
2. 「我的数学课程」按课程 → 章节 → 知识单元 → 习题/证明浏览和创建真实知识对象。课程与章节也有可编辑正文；旧知识可以在不破坏现有构造归属的前提下归入章节或在章节之间移动。标记沿用 `objectContent.tags`，层级沿用 `placements` 的 construct 归属，两者都参与 LKL3 导出/导入，没有平行的新型数据存储。
3. 首页亦可继续最近更新的真实知识，并在「知识工具与数学结构」中使用原有新建、导入和结构库入口。
4. 内容库定位知识/正文/结构，标签页保留正在处理的文档。
5. 中心工作区承载统一正文编辑器、结构画布、搜索、设置与 LKL 手册。
6. 右侧 inspector 编辑当前结构、节点、关系或变量。其上下文来自工作区选中对象。
7. LKL 导入先预览校验再事务提交，导出保留稳定身份与依赖闭包。

不建立新的示例数据、伪统计或独立营销页面。复用实际用户数据；用户浏览器内 IndexedDB 不是源码中的共享数据。

学习入口不宣称自动批改或 AI 教学：目前仅帮助从问题进入可编辑文档、记录独立尝试与复核，并复用原有知识保存与导出机制。课程目录不等于完成度或熟练度统计。进一步的习题反馈必须在具备可验证能力后独立设计。

## 面板系统

顶栏拥有全局命令和路径，文档栏拥有文档历史、标签与画布动作，内容库拥有筛选与层级，inspector 拥有局部属性。不得在多个地方复制同一主动作。

内容库选择与当前文档位置互相对应。保留节点的稳定 ID、引用与所有权差异、已展开路径和滚动定位。导航背景只表示交互状态，不反向定义知识语义。

同一知识直接拥有的结构与正文合并显示在知识导航入口下，默认打开结构。多个结构通过文档栏选择器切换；结构内节点提升为知识入口的子项，多结构时注明结构名称。引用和独立结构仍保留可达路径。这是导航投影，不合并或删除持久化对象。

文档栏「正文」打开与画布并列的正文窗口。知识正文与当前结构说明通过来源选择器分别编辑、自动保存；切换知识默认回到结构，关闭正文将空间还给画布。两个区域独立滚动，窄屏保留可横向滚动的双栏，避免覆盖图形或裁掉正文。

内容库、文档、inspector 分别拥有自己的滚动区，外层页面不滚动；画布保留自身缩放和平移。打开右侧面板在宽屏为中心让出空间，在紧凑屏幕覆盖而非缩小所有控件。关闭后恢复发起控件焦点，导航收起时不可继续 Tab 进入隐藏内容。

内容库支持拖动与方向键调整宽度；分隔条须反映 min/max/current。打开临时内容库后点击工作区或按 Escape 收起。跨越断点时恢复桌面收起偏好。

## 内容规则

标题描述用户任务，正文提供必要背景；不把内部运行时术语放进普通操作路径。空状态说明下一步，并复用已有新建/导入按钮。错误提示说明原因和可执行恢复动作；验证失败保留原输入。

数学符号（如 ℤ/nℤ、B₄）、关系箭头、图形节点形状承担学科含义，不能当装饰图标替换。保留结构、正文、关系和变量的编辑能力及数据往返。
