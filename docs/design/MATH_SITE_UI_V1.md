# LMN 数学网站：学习档案式 UI（第一阶段）

## 设计参照

参考易学网站的六十四卦档案页面：`https://lmn-joeyce.com/#hexagrams/h-100000`。

借鉴的是界面的组织方式，而非卦象分类：清晰的顶部功能导航、宽松的资料卡片、主内容与补充资料分栏、可检索的档案、统一的视觉语言。

数学学习采用自己的对象关系：**知识、问题、方法和学习会话**。本阶段聚焦使用入口与正在学习的会话，不声称已经建设完成自动关联的题库或方法库。

## 交互架构

1. **学习首页**：直接输入数学问题，选择理解概念／证明训练／解题练习／知识整理，开始会话。
2. **学习记录**：从首页跳转至待复习和最近会话；会话与 Knowledge 分开保存。
3. **课程与知识**：可新建课程、章节、知识单元；保留已有内容库与文档编辑功能。
4. **结构工具**：沿用结构库、数学模板与可视化编辑器，作为辅助层而不是学习的强制前提。
5. **探索与检索**：沿用现有搜索和认知检索工作台。
6. **导入资料**：沿用 LKL / JSON 的校验及导入流程；学习会话另有 JSON 档案备份。

首页右栏承担参考档案、示例入口、快捷动作、学习流程提示的角色；进入学习会话时隐藏空内容树，留出真正的思考与书写空间。文档与画布仍保留旧导航。

## 视觉规范

- 主色：深靛蓝 `#3b407d`，辅助浅靛蓝；背景为暖灰纸色 `#f1f0ec`。
- 卡片白底，圆角 `12px`，细边界与轻阴影；避免大型空白工作画布成为首页。
- 知识编辑保留原功能，使用阅读卡片；独立尝试工作区加强任务／书写双栏及步骤按钮的对比。
- `1060px` 开始压缩表单，`780px` 以下将首页转单栏，`540px` 以下简化次要信息；保留用户选择的深色主题。
- 所有动作须连接到既有控制器方法，禁止只有外观而不能执行的按钮。

## 已完成和未完成的边界

已完成：统一页面外观、可操作导航、学习起点与示例、会话和课程入口、旧编辑器／结构库的兼容；可配合未合并的 PR #12 使用。

尚未实现：独立的全量数学题库、方法数据库、跨知识点的智能推荐、在线 AI 自动调用、自动数学评分。这些应在真实学习流程经过验证后建设。

## 发布前检验

- `node --test tests/*.test.js`
- `npm run build:web`（重建模块预加载和 Service Worker 离线缓存）
- 检查首页在桌面和手机上的布局、菜单能否打开、示例能否建立学习会话。
- 提交至 GitHub 后，由 Codex 审核 PR、确认 GitHub Pages 发布分支并按既有流程部署。**勿将本地预览等同于已发布网站。**
