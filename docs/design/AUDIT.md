# UI 一致性审计 · 2026-09-14

## 根因与方案

首页加载 `apps/web/styles.css` 和多个按版本扩展的 refinement 样式。相同导航行在后续文件再次被覆盖为渐变、阴影和大圆角；主题常量散落在控件中，导致深色模式白底浅字；布局断点与工具栏高度也不一致。

沿用现有技术栈和语义模型，抽取唯一主题 token，建立共享控件/工作区规则，删除被替代的导航装饰块，并复用现有原生控件。找到该方案后停止替代架构探索。

## 检查与处理

| 项目 | 结论与处理 |
| --- | --- |
| 重复组件 | 保留共享编辑器、导航与 transient manager；不引入第二套组件框架 |
| 相近颜色、明暗主题 | 主题定义移到 design-tokens.css；工具栏、导航、普通按钮、属性摘要、错误/警告使用语义变量；深色强调色单独映射 |
| 间距、圆角 | 公共控件使用4px间距基数与4/6/8px圆角；几何端口/数学节点形状保留 |
| 重复按钮 | 使用原生 button 的共享规则，图标外壳统一 SVG helper；取消普通按钮阴影和位移 |
| 面板 | 宽屏右侧停靠并让出工作区，窄屏侧浮层；统一滚动、标题、边框；去掉入场位移 |
| 图标语义 | 全局菜单、关闭、导航、历史按钮使用统一16px线性 SVG；数学符号仍按领域语义保留 |
| 无障碍 | 增加跳转链接、dialog名称、搜索标签、tab关系/方向键、菜单键盘/回焦、侧栏inert和分隔条当前值 |
| 深层导航溢出 | 保留深度3之后停止缩进的原约束，前3层使用12px，7层导航回归无横向溢出 |
| 响应式 | 检查1440、1024、768、390px；窄屏导航默认收起，命令入口保留；首页无页面横向溢出 |
| 空/加载/错误 | 保留真实新建与导入入口；错误使用语义色；保存采用礼貌状态播报；不创建伪数据或伪进度 |
| 动效 | 普通反馈120ms，尊重reduced motion；不改变用户要求的数学运动与相机功能 |
| 离线 | 构建生成器包含新增共享CSS/JS；保持完整版本缓存更新 |
