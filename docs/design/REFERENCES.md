# 设计参考边界

本次依据用户提供的产品原则与项目真实实现；工作区内未提供独立截图/设计稿。以下是设计方向，不声称已逐一研究产品最新界面。

| 参考 | 应吸收的方法 | 在 LMN 的落点 |
| --- | --- | --- |
| Linear / Raycast | 紧凑操作、稳定层级、键盘效率 | 控件密度、命令与焦点 |
| Notion / Obsidian | 知识组织、正文与引用关系 | 内容库、统一正文、稳定对象 |
| Figma / VS Code | 多面板职责、局部工具栏、scroll ownership | 导航 / workspace / inspector |
| ChatGPT / Codex | 任务、内容与工具关联清楚 | 命令入口与任务工作区 |

不复制品牌颜色、Logo、原文案、专有素材或完整视觉身份。界面颜色沿用 LMN 自有主题；数学示意由项目真实渲染器生成，不引入装饰图片。
