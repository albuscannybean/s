# 设计参考边界

本轮直接读取了用户指定的 LMN 易学站代码仓库与线上页面：

- 参考仓库：`https://github.com/albuscannybean/yixue-lmn-cbmap`
- 参考页面：`https://lmn-joeyce.com/#hexagrams/h-100000`
- 数学站仓库：`https://github.com/albuscannybean/s`

从易学站吸收的是同一产品系列的界面语言与信息组织：暖灰纸色、靛蓝主色、品牌字形块、顶栏工具、模块导航、细线标签、正文纸面、右侧参考资料区、轻量交互与清晰的阅读层次。数学站保留自己的数学内容与交互，不复制易学站的经文内容、专有数据或业务功能。

数学学习设计以用户 2026-11-11 最新要求为准：拒绝把“问题欲 → 形式结构 → 符号化 → 动作 → 反馈”固化为必经训练链条。核心活动是接触足够丰富的具体样本，观察、比较、发现共同规律，形成猜想与反例，再由学习者决定何时抽象、证明和应用。题目与知识是多对多关系；例子和观察材料不是习题的附属物，而是发现过程的主要入口。

本轮新增发现室与函数列样本集，允许调节参数、改变定义域、比较图像、追踪固定点与移动点，并保存观察、猜想和反例。发现记录复用现有个人批注存储与 JSON 备份，不新增数据库版本。已有题库、知识档案、学习会话、结构编辑、LKL3 和应用数学工具保留。

不复制第三方品牌标识、专有文案或受版权保护的素材。所有新增数学样本均为原创定义，并通过单元测试核验关键数值与跨档案引用。
