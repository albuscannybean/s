# 交互约束

| 场景 | 约定 |
| --- | --- |
| 键盘进入应用 | Tab 首先可见“跳到工作区”；图标有可访问名称 |
| 导航模式 | 一项在 Tab 顺序中；左右键、Home/End 切换，选中状态与面板关联同步 |
| 调整侧栏 | 拖动或左右键以20px调整；220–620px边界，pointercancel 清理监听并保存最终值 |
| 收起侧栏 | aria-expanded 同步，inert 阻止隐藏内容获焦；必要时回到展开按钮 |
| 紧凑窗口 | 内容库默认收起；用户可展开，点击工作区/Escape 收起；不丢弃当前对象或文档 |
| 属性面板 | 打开后焦点进入关闭按钮；关闭时返回仍存在的发起元素；不把普通 inspector 当 modal |
| 原生 modal | 命名标题、浏览器焦点约束、Escape/取消、原生回焦；复杂任务保留原输入 |
| 上下文菜单 | 上下方向键与 Home/End，Enter/Space 使用原生按钮；Escape 关闭并回焦；外部点击关闭 |
| 删除 | 沿用影响预览、明确对象、事务提交与现有撤销；不能为视觉统一绕过确认 |
| 导入 | 解析→验证→预览→用户提交；失败不能覆写现有工作区 |
| 编辑 | 继续使用统一 Markdown/LaTeX 编辑器与现有行内字段；无需只读卡片再加编辑弹窗 |
| 保存与加载 | 保存区域礼貌播报；保持布局稳定；失败保留用户内容并提供恢复入口 |
| 命令 | 保留 Ctrl K、现有注册表及命令选择行为；窄屏也保留可点击入口 |
| 学习入口 | 首页问题文本为必填，原生表单支持 Enter 提交；创建独立学习会话，不在首次打开时创建 Knowledge；会话可通过标签页、首页恢复，整理时才显式创建正文 |
| 独立尝试与提示 | 草稿自动保存但不是已提交的尝试；提交后保留原文与提示使用数。内置提示必须在至少一次独立尝试之后解锁，不自动替学生给出完整解答；切换任务保留每个任务的草稿 |
| AI 反馈 | 网站只导出上下文 JSON，不宣称在线接入模型；外部返回 JSON 先严格检验版本、会话及尝试 ID，再预览、由用户确认才收录。拒绝无关反馈时保留原输入 |
| 复习与档案 | 完成初始尝试后才能安排首轮复习；每轮复习都要求新的回忆提交。学习档案导入先校验、预览数量再合并，不允许静默覆盖较新的本地会话；LKL3 保持独立 |
| 学习目录 | 课程/章节用原生 details 折叠；创建名称沿用已有命名对话框；标题按钮进入统一正文编辑器。习题和证明是普通子知识，可用内容库继续编辑和检索。已有笔记仅当没有其他构造归属时可归档；将笔记从一个学习章节移动到另一个章节不会删除正文 |

hover、selected、focused 是三个不同状态，必须可以叠加。鼠标悬停不能改变当前对象；键盘焦点不能因 DOM 更新无故丢失。长列表采用明确滚动归属，不用移除键盘可达项解决溢出。

结构节点左键单击或 Enter/Space 打开内容；移动超过 5px 后才捕获拖动，拖动结束不触发打开。结构下的正文使用统一正文编辑器，保留结构身份和自动保存。

文档栏的「地图」在结构及其内容中可用，使用原生 dialog；Escape/关闭回到发起按钮。结构选择器可返回所在的上层地图。地图按实际显示的箭头提供下一步，多分支全部列出，平行边合并同一目标；无箭头不推断顺序。当前节点用实心与文字标识，下一步用亮框与独立按钮标识。所有节点支持点击、键盘和原生下拉跳转；无需改变图形或 LKL 数据。

新弹层先判断是否可以使用原生 dialog、select 或现有 transient 管理器。禁止创建另一套 Escape/outside-click 全局处理器。自动化浏览器检查是最低门槛，实际辅助技术验收另行记录，不推断为已经完成。
