# 数学与易学的统一界面

参考项目：`https://github.com/albuscannybean/yixue-lmn-cbmap`；线上界面：`https://lmn-joeyce.com/#hexagrams/h-100000`。只读取参考站源码与公开页面，不修改易学站。

数学站采用同一套 LMN 外壳：暖灰纸色 `#eeece7`、纸面 `#fffefa`、表面 `#f6f4ef`、正文 `#252832`、次要文字 `#747783`、靛蓝 `#353b70`、边界 `#e1ded6`；品牌字形块、顶部资料工具、八项模块导航、细线标签、纸面阅读区与右侧研究资料区保持同一视觉语言。颜色仍由 `packages/ui/design-tokens.css` 的主题变量管理，其他主题偏好继续可用。

数学站顶层导航为：首页、发现、课程、题库、知识、方法、记录、应用数学。公开教材与私人 Knowledge/LKL3 继续分离。文档标签只呈现实际打开的文档，不再重复承担课程和档案导航。资料工具收纳原内容库、结构库、导入导出；原结构能力与私人数据不删除。

## 发现式数学学习

默认入口不再把“提出问题—独立尝试—提示—复习”当作必须遵循的线性流程。首页首先呈现具体样本；发现室允许自由选择对象、改变参数、比较曲线、追踪固定点与移动点，并记录观察、猜想、反例和未解决的问题。用户可以从样本、知识、题目或自己的问题任意进入。

当前第一组材料以函数列为例，包含幂函数列、线性缩放、振荡衰减、移动尖峰、移动峰、有理函数列与端点现象。样本可交互、可比较，并与既有知识档案及习题建立多对多关联。个人观察写入现有 `mathAnnotations` 存储，不引入新的数据库版本；原始观察、猜想与反例可以随批注 JSON 导出。

证明训练、题目提示、AI 反馈与复习仍然保留，但作为学习者需要时调用的工具，不构成所有探索必须经过的固定步骤。

本轮不修改易学站，不改变 Knowledge 身份、LKL3 协议或 IndexedDB 版本。回归需覆盖模块导航、发现样本与数值、固定点/移动点比较、个人观察保存恢复、AI 上下文导出、原结构工具、移动端与离线资源。
