# 禁止模式

- 不为 UI 改造迁移框架、修改知识身份、LKL schema、编译语义或数学模型。
- 不新增 `*-refinement-vN.css`、新一层版本补丁或页面私有 token；修正规范中的公共来源。
- 不在导航、首页、工具栏、普通面板添加装饰渐变、glassmorphism、每行 Card、每 Card 阴影。
- 不使用巨大圆角、胶囊包裹普通标签、装饰 emoji、Hero 或营销文案替代工作入口。
- 不通过过度留白、过大桌面控件、8–10px 小字或隐藏主要功能来解决密度问题。
- 不以占位符替代 label，不以颜色替代状态文字，不移除键盘 outline。
- 不把隐藏面板留在 Tab 顺序，不用无键盘支持的 div 模拟 dialog/select。
- 不复制多份编辑器、菜单关闭逻辑或按钮实现；先复用已有模块。
- 不把所有面板在小屏纵向堆叠，不让整个页面承担表格/代码的横向滚动。
- 不把产品数学图形中的圆、关系箭头、几何坐标当普通 UI 样式清理。
- 不为了界面展示读取、导入或外传真实私人知识；QA 使用隔离浏览器和测试数据。
- 不宣称本地预览等于已上线，不宣称局部浏览器检查等于全产品无障碍认证。
